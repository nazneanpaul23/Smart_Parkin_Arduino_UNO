# Smart_Parkin_Arduino_UNO
*Detecteaza automat vehiculele la intrare folosind un seznor ultrasonic.
*Controleaza bariera de acces cu ajutorul unui servomotor.
*Afiseaza numarul de locuri libere impreuna cu mesajele "Parcare PLina" / "Parcarea Goala" pe un ecran LCD.
*Ofera feedback vizual (2xLED) si sonor(1x Buzzer Pasiv)
*Include butoane fizice pentru resetare si pentru eliberarea manuala a locurilor.
*Am anexat in repository schema electronica, asezarea vizuala a componentelor, componentele necesare, codul C++, demonstratia reala a functionarii proiectului 
*Link Tinkercard: https://www.tinkercad.com/things/5b3fyc8Qof2-parcare-autumata

Smart_Parking_Arduino_UNO
Automatically detects incoming vehicles using an ultrasonic sensor.

Controls the access barrier using a servo motor.

Displays the number of available parking spaces along with "Parking Full" / "Parking Empty" status messages on an LCD screen.

Provides visual feedback (2x LEDs) and audible feedback (1x passive buzzer).

Includes physical push buttons for system reset and manual space release.

The repository includes the electronic schematic, component layout, list of required components, C++ source code, and a real-world demonstration of the project.
